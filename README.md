# DevPulse

Plataforma de análise de produtividade e saúde de projetos hospedados no GitHub.

## Objetivo

O DevPulse utiliza dados provenientes da API do GitHub para gerar métricas,
indicadores e visualizações relacionadas ao desenvolvimento de projetos de
software.

## Tecnologias

### Frontend

- React
- TypeScript
- Vite

### Backend

- Node.js
- TypeScript
- Fastify

### Integrações

- GitHub REST API
